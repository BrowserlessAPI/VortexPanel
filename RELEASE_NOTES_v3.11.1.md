# VortexPanel 3.11.1

## New: Ubuntu 26.04 LTS

The App Store installs and updates VortexPanel software on Ubuntu 26.04, on x86_64
and ARM: Nginx, Apache2, OpenLiteSpeed, Caddy, Caddy WAF, MySQL, MariaDB, PostgreSQL,
MongoDB, Redis, Memcached, PHP 8.1 to 8.5, Node.js, Composer, Docker, Supervisor,
Fail2ban, ClamAV, ModSecurity, BIND9, DDNS Manager and Pure-FTPd.

- Every build was installed and smoke-tested on Ubuntu 26.04 before it was published.
- Builds made once for every Linux system (Caddy, Docker, MySQL, Node.js, ...) are
  offered on Ubuntu 26.04 only when the catalog records that they were tested there.

## Upgrade

Panels on 3.11.0: **Settings > Update**.
